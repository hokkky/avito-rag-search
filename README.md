# Поиск статей справки по обращениям пользователей

Тестовое задание Авито: по обращению в поддержку найти 10 самых релевантных статей справочного центра (793 статьи). Это этап retrieval в RAG-ассистенте поддержки.

**Итог:** MAP@10 0.71 на отложенной выборке против 0.29 у BM25. На жалобах о цене доставки — 0.84 против 0.32 без истории обращений.

## Подход

1. **История обращений в индексе.** К каждой статье добавляются размеченные обращения, которые к ней относятся: статья становится находимой и по своему тексту, и по тому, как о ней спрашивают люди. Это закрывает разрыв между жалобой («почему доставка такая дорогая?») и справочным языком статьи. Вес истории подбирается на валидации.
2. **Два поиска:** BM25 по лемматизированным чанкам и dense-поиск по эмбеддингам [deepvk/USER-bge-m3](https://huggingface.co/deepvk/USER-bge-m3). Затем гибрид — взвешенная сумма скоров.
3. **Реранкер** [BAAI/bge-reranker-v2-m3](https://huggingface.co/BAAI/bge-reranker-v2-m3) на топ-50 гибрида и смесь ранжирований гибрида и реранкера через RRF.
4. **Разбор ошибок:** на каком этапе теряется правильная статья.

## Валидация без утечек

Калибровка (500 запросов) делится пополам. На tune подбираются все параметры, и только tune служит историей обращений; запрос из tune не может найти сам себя (leave-one-out). Holdout в подборе не участвует.

## Результаты на holdout (250 запросов)

| Этап | MAP@10 | Recall@10 |
|---|---|---|
| BM25 | 0.294 | 0.594 |
| BM25 + история | 0.402 | 0.728 |
| Dense | 0.438 | 0.768 |
| Dense + история | 0.575 | 0.874 |
| Гибрид без истории | 0.516 | 0.847 |
| Гибрид + история | 0.679 | 0.929 |
| Гибрид + история + реранкер | 0.656 | 0.937 |
| Смесь гибрида и реранкера | **0.707** | **0.966** |

Осталось 4 провала из 250, и все приходятся на статьи, о которых в истории нет ни одного обращения. Для таких статей следующий шаг — переписывать запрос через LLM перед поиском.

## Стек
